# HCR AAD 使用手册

## 玩家怎么使用

HCR AAD 会跟随 Espetro 对局自动工作，不需要普通玩家输入命令。

- `V`：显示或隐藏战术地图。
- 鼠标滚轮：地图可见时放大或缩小。
- Ping Wheel 的“标点”键：在战场内按住打开战术标点轮盘。

战术地图底图按视野分级加载。地图刚激活时会预热低清预览；首次打开若高清瓦片尚未到达，
会先显示预览或纯色背景，移动、缩放、据点和选点功能不会等待整张图片。关闭后保留低清预览，
再次打开不会重新解码整图。
- `X`：打开战术地图显示设置。
- `打开据点信息`：默认未绑定，请在按键设置中选择一个不与 Espetro 冲突的按键。
- `R`：在据点详情页刷新信息。

地图上会显示当前地图底图、网格、据点、队友以及 Espetro 的 Radio、HAB、Rally、载具补给站等战术对象。只显示当前活动战场的数据。
阵营选择、编制选择、部署或死亡重部署界面打开时，HCR AAD 的界面快捷键不会覆盖当前流程。

## 据点与兵力

进入部署阶段时，系统自动按地图配置建立第一批据点。进攻方依次推进，防守方阻止占领；死亡、占领和地图规则会改变双方兵力。达到胜负条件后，HCR AAD 通知 Espetro结束回合。

据点批次、区域和初始兵力由服主写入该地图的 `CapturePoints.json`。玩家不需要知道文件名或手动开始行动。

## 战术标点

指挥官、小队长、A/B/C 火力组组长，以及合法载具席位都能放置同阵营标点。
按住 Ping Wheel 的标点键会打开 ApricityUI / EsRadial 轮盘；轮盘类型、图标与战术地图一致。
移动鼠标到图标，松开标点键或点击左键确认；右键或 Esc 取消。中心和空槽不放置标点。
扇区大小不等，并留有空槽。选中后
使用 Ping Wheel 的世界射线、最大距离、方向提示、音效和距离缩放。离开 Espetro 战场后，
相同按键仍保持 Ping Wheel 的普通功能。

载具权限按 SBW 的权威载具类型和座位编号判断，Dragonrise 与 FCP 载具同样继承该体系：

- 坦克：0、1、2 号座位；
- APC/步战车与直升机：0、1 号座位；
- 其它类型和其它座位：不可放置。

服务端会检查：

- 玩家位于当前 Espetro 战场；
- 玩家身份或当前载具座位具有权限；
- 坐标在地图边界内。

标点只同步给同阵营的战场玩家。世界瞄准位置还会复核距离、视线方向与遮挡，防止伪造坐标；
战术地图右键则可在整张配置地图内下令。停止游戏、结算或切换地图后，旧标点会立即清空。

## 指挥官技能选点

需要地图坐标的 Espetro 指挥官技能会打开 HCR AAD 的 MUtil 选点窗口。移动和缩放到目标位置后提交，服务端仍会检查战场、地图边界、指挥官身份、游戏阶段与技能冷却。实际技能效果由 Espetro 执行。

## 服主配置一张地图

1. 在 `EsWorld/<地图>/EsConfig/` 中加入 `TacticalMap.json`。
2. 在同一目录加入 `CapturePoints.json`。
3. 如需底图，把 PNG 放入同一目录并在 `backgroundImage` 中写相对文件名。
4. 完整重启服务器。
5. 查看 Espetro 启动日志，确认地图通过校验。
6. 正常开始 Espetro 对局；无需运行 HCR AAD 的加载或开始命令。

可直接参考 Espetro 随附的 `EsWorld/test_flat/EsConfig/` 示例。全部字段见
[CONFIGURATION.md](CONFIGURATION.md)。

## 生命周期与地图重置

HCR AAD 不读取或写入当前存档的维度文件，也不修改 `EsWorld`。地图激活时只接收 Espetro 已冻结的配置和底图字节：

```text
EsWorld 只读模板
  -> Espetro 本局临时战场
  -> HCR AAD 内存中的地图/据点快照
  -> 对局结束后全部清空
```

执行 `/espetro stop` 后，玩家返回主城，HCR AAD 清理据点、兵力、底图、标点和同步缓存，Espetro 卸载并删除本局临时战场。下一局选择同一地图时会得到一份全新的副本。

## 管理员兼容功能

`/hcrpi` 下的命令保留用于排错和旧流程。日常对局不需要它们。

- `mapctrl`：控制是否显示玩家位置。
- `teamfight nextbatch`：管理员手动推进批次。
- `teamfight saveconfig`：将当前内存状态导出到 `config/espoints/exports/`。
- `teamfight loadconfig`：恢复当前地图在服务器启动时冻结的快照，不重新读取磁盘。

导出文件只是管理员参考副本，不会自动变成地图配置。确认内容后应在服务器关闭时手工更新
`EsWorld/<地图>/EsConfig/CapturePoints.json`，再完整重启。

## 常见问题

### 战术地图不可用

确认客户端和服务器都安装 HCR AAD、Espetro、MUtil、Ping Wheel 1.12.1，并使用相互匹配的版本。再检查地图是否因配置错误被 Espetro拒绝。

### 底图是空白

底图必须是同一 `EsConfig/` 内不超过 16 MiB 的真实 PNG。`backgroundImage` 只能写安全相对路径。

### 据点没有出现

据点在部署阶段开始时创建。检查 `CapturePoints.json` 是否有第一批据点、坐标是否覆盖预期区域，以及地图是否成功激活。

### 仍看到上一局数据

使用正常结算或 `/espetro stop` 结束上一局。若问题仍存在，检查服务器日志是否收到战场清理事件，并确认双方使用当前同步构建。
