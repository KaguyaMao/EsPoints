# Squad 分类标点（EsRadial 0.3.1）

客户端和服务端需同时使用本次版本：EsPoints 1.1.1d、Espetro 1.1.3-k、EsRadial 0.3.1、PingWheel 1.12.1。
EsPoints 网络协议由15升到16；旧枚举的前8个序号保留，新类型追加，但旧客户端无法识别新类型，因此禁止混接。

## 目录

- 敌情 → 步兵：普通步兵、机枪手、轻/重反坦克、狙击手。
- 敌情 → 载具 → 装甲：坦克、步战、运输车、履带步战/运输车、侦察车。
- 敌情 → 载具 → 轻型：吉普、武装/反坦克吉普、摩托、快艇。
- 敌情 → 载具 → 后勤与支援：后勤、运输、防空、火炮载具。
- 敌情 → 空中目标：运输/武装/侦察直升机、无人机、固定翼。
- 敌情 → 敌方据点：电台、兵站、集结点、维修站。
- 敌情 → 固定武器：迫击炮、机枪、反坦克、防空阵地。
- 敌情 → 危险物：地雷、IED。
- 战术指令 → 行动：进攻、防守、移动、观察。
- 战术指令 → 补给与接送：弹药、建材、接送。

每个目录最多6个项目；不会把全部标点平铺到同一轮盘。155炮击点继续由专用炮击入口提供。

世界标点：在打开菜单前保存瞄准位置，进入子菜单不会改变位置；最终放置仍使用原服务端权限、边界、射线、距离和冷却校验。
地图标点：右键地图空白处打开同样的分类轮盘，在最初点击的位置放置；点击内圈返回按钮，Esc取消。原有左键删除自己的标点和炮击目标选择保持可用。

## 地图载具

地图使用提供的 mark 素材：白色己方、红色敌情。敌情标点需人工放置，不自动透露敌方载具。
服务端每10tick向有地图订阅的己方玩家同步 Espetro 追踪载具，包含位置、朝向、乘员数量和所属小队。
未加载载具使用最后已知位置并淡显，不强制加载区块；销毁或帧过期后取消显示。悬停显示状态。
默认图标按载具类型名匹配；自定义未知类型使用白色通用载具图标。

布局文件、F6拖动和Tab吸附由 EsRadial 提供。地图与世界同一菜单ID共用保存布局；地图中的布局在世界轮盘F6调整。
