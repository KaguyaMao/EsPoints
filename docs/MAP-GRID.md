# 固定地图网格

EsPoints 1.1.1d，配套 EsRadial 0.3.1 / Espetro 1.1.3-k。使用当前地图的 `showGrid` 开关。

- 左上角固定为当前地图边界的 `minX,minZ`，与 `(A,1,1,1)` 左上角重合；X 向右，Z 向下。
- 大格始终 150×150 方块，横向 A…Z、AA…，纵向 1、2…。地图大小只决定格子数量，不改变格子尺寸。
- 每个大格 3×3 中格，每个中格 50×50；每个中格 3×3 小格，小格边长精确为 50/3，不取整。
- 中格、小格均按从左到右、从上到下编号：第一行 1、2、3，第二行 4、5、6，第三行 7、8、9。
- 鼠标悬停显示 `(大格字母,大格数字,中格数字,小格数字)`，高亮父格和当前小格。标记的实际 X/Z 同时保留。
- 缩放、平移保持原点及编号；远景只隐藏过密细线。右/下残格裁切，不拉伸。边界属于右侧/下侧；地图最大 X/Z 边界不生成悬停坐标。
- 上边显示字母标尺，左边显示数字标尺；提示框避开鼠标并限制在地图内部。放大后显示悬停父格的 1–9 编号。

650×430 地图示例：相对左上角 `(225,385)` 为 `(B,3,5,8)`；`(649,429)` 为 `(E,3,7,6)`。

实现：`tactical/TacticalMapGrid.java` 负责纯坐标计算；`hud/TacticalMapGridRenderer.java` 负责投影、层级线条、标尺和提示，地图图标及服务器权限使用既有逻辑。没有新增网络协议。

轮盘右键不返回或关闭。子分类使用轮盘上方的“返回”按钮；Esc 或松开唤出键取消整个轮盘。地图空白处右键仍用于首次打开标点轮盘。
